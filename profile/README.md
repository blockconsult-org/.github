## Research workbench

[Block Consult DD](https://github.com/blockconsult-org/block-consult-dd) is the full desktop workbench for due-diligence cases: intake, evidence, research, findings, scorecards and branded reports. [Download for macOS or Windows](https://github.com/blockconsult-org/block-consult-dd/releases/latest).

It has an English interface, stores case records locally and supports rule-based checks without an account. Optional AI research and drafting use your own provider account and send relevant case material to that provider. Apple silicon and Intel Macs have separate installers. See its README for data handling and release details.

## Choose how you work

- **Desktop planning tools:** universal macOS DMGs for Apple silicon and Intel; Windows x64 installers and portable executables. Each release includes checksums and the signing status.
- **Browser planning tools:** [open the tools online](https://www.blockconsult.org/tools) without installing anything.
- **Source:** clone an individual repository, inspect the assumptions, run the tests and adapt the tool under the MIT license.

For the seven planning tools, inputs stay on your device. JSON files let you move work between devices, and optional share links carry readable snapshots. The apps have no telemetry, accounts, cloud sync or background uploads.

For installation, methodology and model limitations, see each repository's README. For work beyond a planning tool, [meet Block Consult](https://www.blockconsult.org).
